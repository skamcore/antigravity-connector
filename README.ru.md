# Antigravity Connector

**by skam** · Windows · RU / EN · v0.1.9

[English](README.md) · [Руководство пользователя](docs/manual.ru.md) · [Архитектура и разработка](docs/development.ru.md)

Небольшая Windows-программа для запуска Antigravity через локальный HTTP/SOCKS5-прокси вашего подключённого VPN или распознаваемый системный туннель. Одно окно настроек, кнопка переключения языка и ярлык на рабочем столе. Без ключей из групп, подписки на коннектор и встроенного VPN-сервиса.

## Скачать и запустить

1. Установите Antigravity и подключите свой VPN.
2. Скачайте **AntigravityConnect-Setup.exe** из [Releases](https://github.com/skamcore/antigravity-connector/releases/latest).
3. Откройте файл, разрешите использование VPN и нажмите **Включить**.
4. В дальнейшем запускайте Antigravity через меню «Пуск» либо открывайте **Antigravity Connector** на рабочем столе и нажимайте **Открыть Antigravity**.

Коннектор не подключает VPN за вас: VPN должен оставаться включённым. Вход в Google по-прежнему нужен. У файла нет цифровой подписи: SHA-256 можно сверить с файлом контрольных сумм релиза. Не отключайте защиту Windows ради непроверенного файла.

## Какие изменения вносит программа

Устанавливается в локальные данные пользователя, сохраняет и изменяет подходящие ярлыки, запускает локальный ретранслятор на случайном loopback-порту. Передаёт прокси-настройки процессу Antigravity. Для двух конкретных серверов Google меняет адрес назначения и разбивает TLS-запись, сохраняя байты рукопожатия и проверку сертификата.

Также заменяет найденные строки `ineligible` на `inexigible` в `language_server.exe` / `agy.exe` Antigravity, предварительно сохраняя копии. **Кнопка «Отключить» восстанавливает ярлыки, но не изменённые бинарные файлы Antigravity.** Для возврата файлов производителя переустановите Antigravity. Подробности — в [руководстве](docs/manual.ru.md).

## Совместимость и ограничения

- Windows 10/11, API .NET Framework 4.5+; рекомендуется .NET Framework 4.8. Поиск Antigravity — только в стандартных каталогах установки.
- Реальное подключение проверялось с Happ. HTTP/SOCKS5 дополнительно проверяются локальными тестами. Все VPN-клиенты и конфигурации Windows не проверены.
- TUN определяется по именам сетевых адаптеров: это не доказательство выхода через VPN и не блокировка трафика при его отключении.
- Успешная проверка соединения не гарантирует доступность аккаунта или ответ модели.
- После смены VPN полностью перезапустите Antigravity. Уже работающий процесс сохраняет прежнее окружение.

Из корня репозитория в Windows:


Результат: `outputs/AntigravityConnect-Setup.exe`. NuGet-пакеты не нужны. См. [разработку](docs/development.ru.md), [результаты ревью](docs/review.ru.md) и [историю изменений](CHANGELOG.md).
