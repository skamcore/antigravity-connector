# Руководство пользователя

## Требования

Windows 10/11, желательно .NET Framework 4.8, установленная Antigravity IDE, аккаунт Google с доступом к сервису и собственный работающий VPN. Для запуска скачанного EXE Python и PowerShell не нужны. Проверка соединения и Antigravity требуют интернета.

Приложение ищет `Antigravity/Antigravity.exe` в локальном `Programs`, Program Files и Program Files (x86). Выбора пути в интерфейсе нет. Для изменения файлов в защищённой папке могут понадобиться дополнительные права. Обычная пользовательская установка не требует системной службы.

## Первый запуск

Закройте Antigravity, подключите VPN и запустите установочный EXE. Включите **Использовать мой VPN**. Если VPN работает в TUN, оставьте **Системный туннель** включённым; локальный прокси проверяется первым. Выберите создание ярлыка и нажмите **Включить**. Программа проверит связь с Google, установит коннектор и ярлыки, затем откроет Antigravity.

Если Antigravity уже запущен, откроется существующий экземпляр: изменить его прокси-окружение задним числом нельзя. Для применения маршрута полностью завершите Antigravity и запустите через коннектор.

## Управление

| Элемент | Действие |
| --- | --- |
| RU / EN | Мгновенно меняет и запоминает язык. Несохранённые настройки подключения не меняются. |
| Использовать мой VPN | Нужно для включения и проверки через интерфейс. Для отмены сохранённого разрешения нажмите «Отключить». |
| Системный туннель | Разрешает распознаваемый активный VPN-адаптер как запасной путь, если локальный прокси не найден. |
| Ярлык на рабочем столе | При сохранении создаёт или убирает собственный ярлык коннектора. |
| Включить / Сохранить и включить | Проверяет связь, сохраняет параметры, устанавливает ярлыки и запускает Antigravity. |
| Открыть Antigravity | Запускает приложение с сохранёнными настройками. |
| Проверить VPN | Проверяет TLS и HTTP-ответы двух серверов Google, но не запрос к модели. |
| Отключить | Восстанавливает сохранённые ярлыки и отменяет разрешение. Уже начатый сеанс завершается обычным образом. |

Статус **Помощник включён** означает сохранённую настройку, а не постоянную проверку интернета. Простое снятие переключателя разрешения не отключает текущую установку: используйте кнопку **Отключить**.

## Ежедневное использование и VPN

Сначала подключайте VPN. Запускайте Antigravity из обновлённого ярлыка меню «Пуск», подходящего заменённого ярлыка или кнопкой коннектора. Прямой запуск Antigravity.exe проходит мимо помощника. Это интеграция через ярлыки, а не перехват всех возможных способов запуска.

Проверяются включённый локальный системный прокси Windows, распространённые порты и слушающие порты процессов известных VPN-ядер. Поддерживаются HTTP CONNECT и SOCKS5 без авторизации. Удалённые прокси с паролем, PAC-скрипты и импорт подписок не поддерживаются. Подписки и пароли VPN не читаются.

В TUN используются обычные маршруты Windows. Активный адаптер не доказывает полный туннель, нужный маршрут или страну выхода. При раздельной маршрутизации часть адресов может идти вне VPN. Блокировки трафика при обрыве и переключения маршрута на лету нет. После изменения соединения переподключите VPN и перезапустите Antigravity.

## Файлы и приватность

Обычный каталог: `%LOCALAPPDATA%/Antigravity Connect`. Упакованное приложение, запускающее установщик, может перенаправить этот путь; реальное расположение видно в свойствах установленного ярлыка.

| Файл | Назначение |
| --- | --- |
| AntigravityConnect.exe | Программа и ретранслятор на время сеанса |
| connector-v4.ico | Иконка ярлыка |
| settings.json | Разрешение, TUN/ярлык, язык, путь Antigravity |
| shortcuts.json | Исходные байты ярлыков и данные восстановления |
| connection.log | Время, маршрут, ошибки и счётчики сеансов |
| check-result.txt | Последняя успешная CLI-проверка; результат может устареть |
| backups/*.bin | Исходные бинарные файлы Antigravity с именем по SHA-256 |

В программе нет аналитического сервера, аккаунта коннектора или автоматической загрузки логов. Проверка соединения обращается к Google. Логи и копии ярлыков могут содержать локальные пути: проверяйте их перед отправкой. Ретранслятор слушает только IPv4 loopback, не требует авторизации и во время работы доступен другим локальным процессам. TLS-трафик не расшифровывается, корневой сертификат не устанавливается.

## Обновление, отключение и удаление

Перед обновлением закройте Antigravity и окна коннектора: работающий EXE заменить нельзя. Запустите новый установщик и включите программу. Автообновления нет.

Отключение восстанавливает ярлыки, которые всё ещё принадлежат коннектору; чужие замены сохраняются. Ранее удалённые при миграции ярлыки могут вернуться, если существовали до установки. Отключение не восстанавливает изменённые бинарные файлы Antigravity, не удаляет копии и не обрывает активный сеанс ретранслятора.

Для удаления нажмите «Отключить», закройте приложения, сохраните нужные резервные копии и удалите каталог установки. Для восстановления файлов Antigravity переустановите её из официального установщика. Не заменяйте новую версию старой резервной копией. Коннектор намеренно не удаляет профиль Antigravity и данные входа Google.

## Решение проблем

- **VPN не найден:** подключите VPN и включите локальный HTTP/SOCKS-прокси либо распознаваемый TUN. Программа сама VPN не подключает.
- **EOF / ошибка настройки аккаунта Google:** полностью завершите Antigravity, переподключите VPN, выполните проверку и повторите запуск. Проверка сети не подтверждает доступность аккаунта.
- **Требуется проверка совместимости:** отсутствует ожидаемый файл или маркер. Нужна проверка новой версии Antigravity; её совместимость не предполагается автоматически.
- **Нет доступа / обновление не удалось:** закройте работающие экземпляры, проверьте каталог и права. Запущенный EXE нельзя перезаписать.
- **Снова просит войти:** сохраняйте прежний профиль и проходите обычный вход. Коннектор не предоставляет аккаунт и не гарантирует сохранение сеанса.
- **Старый ярлык / нет иконки:** откройте актуальный установщик и сохраните настройки. Цель ярлыка должна быть AntigravityConnect.exe. Проводник может показывать иконку из кеша.

В сообщение об ошибке добавьте версии коннектора, Windows и Antigravity, название и режим VPN, точный текст ошибки и очищенный от личных данных фрагмент лога. Не отправляйте пароли, токены, подписки и папки профиля целиком.
