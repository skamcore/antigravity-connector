# Ревью выпуска v0.1.8

Дополнение v0.1.9: чистая английская Windows в CI выявила сбой сохранения кириллического ярлыка через WScript.Shell. Shortcut.cs теперь использует Unicode IShellLinkW/IPersistFile; тест русского имени сохранён. Для компилятора явно задан UTF-8. При повторных локальных запусках один тест ретранслятора завершился временным сбоем ожидания; последующий полный аудит прошёл. Это не подтверждает надёжность во всех сетевых условиях.

Дата: 04.11.2026. Проверены C#-код, установщик, ретранслятор, переводы, тесты, сборка и состав публикации. Это ревью и регрессионная проверка, а не гарантия отсутствия багов или сертификат безопасности.

## Исправлено

- Сохранение Desktop=false теперь удаляет существующий собственный ярлык коннектора, включает удаление в откат и позволяет включить ярлык снова. Чужой одноимённый ярлык не удаляется.
- CLI --check требует сохранённого разрешения и учитывает AllowTunnel вместо безусловного включения TUN.
- Добавлена небольшая подпись by skam без изменения сценария подключения.
- После успешного отключения очищается история ярлыков: следующее включение сохраняет актуальные пользовательские версии. Добавлен тест изменения исходного ярлыка между установками.

## Проверки

Изолированный аудит прошёл локально в Windows. Он проверяет протоколы, сохранность TLS-байтов, жизненный цикл ретранслятора, откат установки, миграцию ярлыков и сохранение языка. Релиз также собирается из подготовленного дерева публикации. Пользовательских настроек, логов, токенов, резервных копий Antigravity и EXE исходного проекта в публикации нет.

Ранее вручную проверялись путь через Happ и транспортная связь с обоими серверами Google. Этот выпуск не заявляет свежую проверку ответа модели, поддержку всех VPN и доказанную маршрутизацию каждого TUN-адаптера. Результаты удалённого CI доступны во вкладке Actions.

## Оставшиеся ограничения

- Для обновления EXE нужно закрыть работающий коннектор; отложенного обновления нет.
- Определение TUN эвристическое: возможен маршрут вне VPN. Kill switch нет.
- Выбирается первый прокси, успешно согласовавший соединение; после TLS-ошибки другой автоматически не выбирается.
- Уже работающий Antigravity сохраняет прежнее окружение; прямой запуск EXE проходит мимо помощника.
- Совместимость патча определяется по маркеру; «Отключить» автоматически не восстанавливает бинарные файлы.
- Для установленных соединений нет тайм-аута простоя и ограничения числа клиентов. Ретранслятор доверяет локальным процессам.
- Логи не ротируются. CLI-файл успешной проверки может устареть: проверяйте код завершения.
- Системные ошибки сети и прав могут отображаться на языке Windows.

Это известные ограничения выпуска, а не утверждение, что найдены абсолютно все проблемы.
